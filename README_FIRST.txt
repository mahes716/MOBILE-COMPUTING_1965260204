4. 04_FitForge_Online_Fitness.html

RUN IN CHROME
1. Extract the ZIP file.
2. Double-click any .html file.
3. Register a demo account and test the features.

RUN IN VS CODE (recommended for lab demonstration)
1. Install Visual Studio Code.
2. Open the extracted folder using File > Open Folder.
3. Install the Live Server extension by Ritwick Dey.
4. Right-click the desired HTML file and choose Open with Live Server.

FEATURES
WellNest: login/register, health routine library, self-care library, breathing timer, mood check-in and local journal.
CareerLane: login/register, personal profile, resume file selection, sample job search/filter, demo application tracker and plan selection.
ParkWise: login/register, sample parking slots, availability counts, booking confirmation, booking history and cancellation.
FitForge: login/register, fitness tips, general meal ideas, workout cards and demo subscription selection.

LIMITATIONS
These are front-end demonstration projects, not production systems. Account details are stored in browser localStorage with demo passwords; do not use real passwords. Resume selection does not upload files to a server. Parking availability is sample data. Subscriptions do not collect payments. Workout cards are not connected to video streams. A production deployment needs a secure backend, database, hashed passwords, server-side validation, secure file storage and a payment provider.
