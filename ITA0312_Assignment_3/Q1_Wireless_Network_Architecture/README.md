
# Q1 - Wireless Network Architecture and Mobility Analysis

## Part A - Introduction to Wireless Networks

### Architecture
Infrastructure-based wireless network consisting of mobile nodes,
wireless access points, routers and a destination server.

### Characteristics
- Mobility
- Limited bandwidth
- Signal interference
- Dynamic connectivity
- Handoff
- Wireless security

### Communication Flow
Mobile Node -> Access Point -> Router -> Server

### Implementation
Python-based wireless communication simulation.

### Execution
python network_simulation.py

### Evaluation Metrics
- Total packets
- Successful packets
- Failed packets
- Packet Delivery Ratio
- Average Transmission Delay
